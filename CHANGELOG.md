# Changelog

Every release lists the icons that were added, renamed, removed, redrawn or moved to another category since the release before.

## 5.0.0-beta.1

First release of coolicons 5: 1219 icons with 11 aliases in 30 categories, each in five styles (Line, Duocolor, Duotone, Fill, Bulk) and three corner radii (Sharp, Regular, Round).
